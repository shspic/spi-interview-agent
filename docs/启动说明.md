# SPI面试Agent 启动说明

## 1. 项目简介

SPI面试Agent 是一个基于 FastAPI、React、SQLite、ChromaDB、DeepSeek、Tavily 和 LangGraph 的 AI 面试训练与岗位匹配系统。

系统支持：

* 本地知识库文件上传
* Markdown / TXT / PDF 文档解析
* ChromaDB 向量检索
* DeepSeek 大模型问答
* RAG 自由问答
* 岗位 JD 分析
* 模拟面试与回答评价
* Tavily 联网搜索
* LangGraph Agent 自动路由
* Agent 路由原因记录
* Agent 执行轨迹记录
* 历史记录查看
* 系统状态自检

## 3. 后端启动

### 3.1 进入后端目录

```powershell
cd D:\spir\NO1_agent\backend
```

### 3.2 激活 Python 虚拟环境

```powershell
.\.venv\Scripts\activate
```

激活成功后，终端前面应该出现：

```text
(.venv)
```

### 3.3 安装后端依赖

首次运行或依赖变动后执行：

```powershell
pip install -r requirements.txt
```

### 3.4 启动 FastAPI 后端

```powershell
uvicorn app.main:app --reload
```

启动成功后，终端应出现类似：

```text
Uvicorn running on http://127.0.0.1:8000
```

后端地址：

```text
http://127.0.0.1:8000
```

Swagger 接口文档地址：

```text
http://127.0.0.1:8000/docs
```

## 5. 环境变量配置

后端需要配置：

```text
backend/.env
```

示例内容：

```env
DEEPSEEK_API_KEY=your_deepseek_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat

TAVILY_API_KEY=your_tavily_api_key

CHROMA_PERSIST_DIR=data/chroma_db
UPLOAD_DIR=data/uploads
SQLITE_DB_PATH=data/app.db
EMBEDDING_MODEL_NAME=BAAI/bge-small-zh-v1.5
```

注意：

```text
backend/.env 不能提交到 Git。
```

`.gitignore` 中应包含：

```gitignore
.env
*.env
backend/.env
backend/data/
backend/.venv/
frontend/node_modules/
```

## 7. 推荐演示流程

完整演示项目时，建议按下面顺序：

1. 打开系统状态页，确认后端、API Key、数据库、知识库状态正常；
2. 进入知识库管理页面；
3. 上传 Markdown / TXT / PDF 文件；
4. 点击“重建知识库索引”；
5. 查看知识库状态，确认向量片段数正常；
6. 进入自由问答页面，测试基于本地知识库的 RAG 问答；
7. 进入岗位分析页面，粘贴岗位 JD，测试本地知识库分析；
8. 开启 Tavily 联网搜索，测试岗位分析增强效果；
9. 进入模拟面试页面，生成面试问题；
10. 输入回答并获取评分、问题分析和参考回答；
11. 进入 LangGraph Agent 页面；
12. 测试 auto / local / web / hybrid 四种模式；
13. 查看 Agent 的实际路由、路由原因和执行轨迹；
14. 进入历史记录页面；
15. 查看自由问答、岗位分析、Agent、模拟面试记录。

## 9. 常见问题

### 9.1 前端显示后端连接失败

检查后端是否已启动：

```powershell
cd D:\spir\NO1_agent\backend
.\.venv\Scripts\activate
uvicorn app.main:app --reload
```

并确认前端请求地址是：

```text
http://127.0.0.1:8000
```

---

### 9.2 DeepSeek 请求失败

检查：

```text
backend/.env
```

确认：

```env
DEEPSEEK_API_KEY=your_deepseek_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

然后重启后端。

---

### 9.3 Tavily 联网搜索失败

检查：

```env
TAVILY_API_KEY=your_tavily_api_key
```

然后重启后端。

如果仍然失败，可能是网络连接问题或 Tavily API 访问被中断。

---

### 9.4 知识库没有检索结果

可能原因：

1. 没有上传文件；
2. 上传后没有重建知识库索引；
3. 文件内容太少；
4. 问题与知识库内容不相关；
5. embedding 模型首次加载较慢。

处理方式：

1. 上传有效的 `.md / .txt / .pdf` 文件；
2. 点击“重建知识库索引”；
3. 查看知识库状态中的向量片段数；
4. 再进行 RAG 问答或 Agent 测试。

---

### 9.5 修改前端代码后页面没变化

尝试：

```text
Ctrl + F5
```

或者停止前端后重新启动：

```powershell
cd D:\spir\NO1_agent\frontend
npm run dev
```

---

### 9.6 修改后端代码后接口没变化

确认后端终端仍在运行，并观察是否自动 reload。

必要时停止后端后重新启动：

```powershell
cd D:\spir\NO1_agent\backend
.\.venv\Scripts\activate
uvicorn app.main:app --reload
```

## 10. Git 提交前检查

提交前执行：

```powershell
cd D:\spir\NO1_agent
git status
```

确认不要提交：

```text
backend/.env
backend/data/
backend/.venv/
frontend/node_modules/
```

检查是否有敏感文件被 Git 跟踪：

```powershell
git ls-files
```

如果发现误追踪 `.env`：

```powershell
git rm --cached backend/.env
```

如果发现误追踪数据库或上传文件：

```powershell
git rm -r --cached backend/data
```
